# Security policy

## Supported versions

Only the latest commit on `main`, which is also what https://ardacankyaa.github.io/rimvo/ serves, receives security fixes.

## Reporting a vulnerability

Please report security problems privately, not in a public issue:

1. Open the repository's **Security** tab and choose **Report a vulnerability**.
2. Describe the problem, the affected browser and the steps or file that reproduce it.

If private reporting is not available, open an issue that only asks for a private contact. Do not include details there.

You can expect a first reply within 7 days. Fixed problems are credited in the release notes unless you prefer otherwise.

## Scope

RIMVO runs entirely in the browser and has no server, accounts or uploads. Relevant reports include, for example:

- a crafted audio file or saved session that runs script, escapes the page or corrupts other saved data;
- personal music, recordings or session data leaving the device;
- a dependency vulnerability that is reachable from the application.

Problems in GitHub Pages hosting itself should be reported to GitHub.
